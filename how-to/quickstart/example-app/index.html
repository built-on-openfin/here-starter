FDC3 & Notifications Starter App

A minimal reference app for building on the HERE Enterprise Browser. It demonstrates FDC3 interop (context listening and broadcasting) and HERE notifications, so you can see the platform's core app-to-app functionality working end to end before building your own integration.

👂

FDC3 Listening

Registers an fdc3.addContextListener() for any context type. Incoming context is shown as raw JSON below; if the context is an fdc3.contact, it's also rendered as a Contact Card.
